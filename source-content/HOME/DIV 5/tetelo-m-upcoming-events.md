## Upcoming Events Block Behaviour

The large block on the left displays the active event poster or photograph.

When the active event changes:

1. Change the image on the left to the corresponding event image.
2. Update the event date, title, location and details on the right.
3. Update the **Add to Calendar** button with the active event's information.
4. Keep the **Get Tickets** button hidden for every Tetelo M event because no ticket links were supplied.
5. Do not show an empty, disabled or placeholder ticket button.
6. Order the events chronologically, beginning with the closest upcoming date.
7. Once an event date has passed, remove it from the upcoming-events rotation or move it to an archive.
