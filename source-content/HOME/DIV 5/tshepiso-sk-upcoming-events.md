## Upcoming Events Block Behaviour

The large block on the left displays the active event poster or photograph.

When the event changes:

1. The image on the left changes to the corresponding event image.
2. The event date, title, location and details on the right update.
3. The **Add to Calendar** button updates with the active event's information.
4. The **Get Tickets** button is shown only when the active event has a booking link.
5. When an event has no ticket link, the **Get Tickets** button must disappear completely rather than appearing disabled.
