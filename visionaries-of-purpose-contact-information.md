## WhatsApp Contact Button

The WhatsApp button should appear directly below the contact form or next to the form submission button.

It should be bold, highly visible, mobile-friendly, and easy to tap.

### WhatsApp Button Text

```text
Chat With Us on WhatsApp
```

### WhatsApp Link Format

Replace the placeholder number with the official Visionaries of Purpose WhatsApp number.

```html
<a
  href="https://wa.me/27XXXXXXXXX?text=Hello%20Visionaries%20of%20Purpose%2C%20I%20would%20like%20to%20make%20an%20enquiry."
  class="whatsapp-button"
  target="_blank"
  rel="noopener noreferrer"
>
  Chat With Us on WhatsApp
</a>
```

### Important WhatsApp Number Rule

The number inside the WhatsApp link must:

- Include the country code
- Exclude the plus sign
- Exclude spaces
- Exclude brackets
- Exclude hyphens

Correct example:

```text
27821234567
```

Incorrect example:

```text
+27 82 123 4567
```

## Contact Form Layout

The contact section should use a clean two-column layout on desktop.

### Left Column

Display:

- Phone number
- Email address
- Business hours
- Short contact message
- WhatsApp button

### Right Column

Display the enquiry form with the following fields:

- Full Name
- Email Address
- Phone Number
- Enquiry Type
- Message
- Submit Button

On mobile devices, the columns should stack vertically. The contact information should appear first, followed by the form.

## Visual Direction

The contact section should feel premium, welcoming, and purposeful.

Use:

- Bold typography for headings and contact details
- Strong spacing between each contact method
- Rounded neomorphic cards
- Realistic depth and soft shadows
- Clean red, black, white, or neutral brand gradients
- A large and highly visible WhatsApp button
- Clear hover, focus, and pressed states
- Bold text throughout, including the smallest supporting text

Avoid:

- Thin typography
- Unnecessary decorative icons
- Generic AI-style symbols
- Excessive glow
- Visual clutter
- Too many colours
- Hidden or difficult-to-read contact details
